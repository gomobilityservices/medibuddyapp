# Connect & Earn

We plan to make a app where people can call or chat with other people by paying a per minute fees. There will be two user roles : Person who is giving service : Will have a per minute rate, spoken languages, profile photo, rating, description etc. He / she will have a gender and preference for what kind of people they want to be connected to. Also they will have a wallet which will earn money when these people provide any service ( call / chat ) and it will show how much money they have earned from each transaction, each day etc. Each person can toggle the status as available / offline. They will be shown to customers only when status is available. Person who is taking service : Can see all available persons in there area. Can select any person to chat / call. Will have a wallet which they will load using money and for every call / chat money will be debited from there account on per minute basic. They will also have basic profile info like name, gender etc Constraints : 1. Customer and service providers should not see each other contact info directly 2. When a call or session is started based on balance available in customer wallet and charge of current call / service, he / she will see the remaining time for current call / session 

Design the UI of the app keeping in mind that we plan to use it as a webview for a mobile app. Out customers will use it on mobile screens so UI should be panned and optimized for mobile screens
